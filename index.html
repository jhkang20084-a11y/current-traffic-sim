🚗⚡ 전류는 교통 흐름이다

자동차 = 전하, 1초 동안 계수기를 지나가는 자동차 수 = 전류. 전선은 넓은 5차선 도로, 니크롬선(저항)은 좁은 터널입니다.

터널이 길수록 차들이 좁은 터널을 빠져나가는 데 오래 걸려 입구 정체가 심해지고, 1초 동안 지나가는 차의 수(전류)가 줄어듭니다. → 저항은 길이에 비례.
터널이 넓을수록(차로 수가 많을수록) 여러 줄로 동시에 지나갈 수 있어 정체가 줄고 전류가 커집니다. → 저항은 단면적(굵기)에 반비례.
직렬 = 터널이 한 줄로 이어짐. 터널 개수가 늘수록 모든 차가 더 많은 터널을 지나야 하므로 정체가 심해지고 전류가 작아집니다 (전체 저항 ↑).
병렬 = 터널이 여러 줄로 나란히. 터널 개수가 늘수록 차들이 여러 갈래로 나누어 지나가므로 정체가 줄고 전류가 커집니다 (전체 저항 ↓). 병렬에서 각 터널을 지나는 차의 수를 모두 더하면 계수기(전류계)에서 센 값과 같습니다.

병렬연결터널 여러 개가 나란히 — 길이 여러 갈래로 나뉨
전압(전지)차를 앞으로 밀어주는 힘 — 전지를 늘리면 모든 차가 더 빨리 움직임

⚠️ 비유의 한계 (선생님 참고)

  • 실제 회로에서 전하는 사라지거나 생겨나지 않습니다. 시뮬레이션에서도 자동차 수는 처음부터 끝까지 그대로입니다.
  • 자동차 진행 방향은 전류의 방향(+극 → 도선 → −극)입니다. 실제 전자는 반대 방향으로 움직입니다.
  • 실제 도선 속 전자는 매우 느리게 이동하지만, 전기 신호는 회로 전체에 거의 동시에 전달됩니다. 그래서 실제 회로에서는 시뮬레이션처럼 "입구에만 줄이 길게" 생기지는 않고, 회로 전체의 흐름이 함께 느려집니다.
  • 터널(저항)에서 차들이 비비며 지나가는 것처럼, 니크롬선에서는 전기 에너지가 열로 바뀝니다.
  • 저항이 아주 작아지면(넓고 짧은 터널을 여러 개 병렬로) 도로 자체가 차를 다 실어 나르지 못해 계수기 값이 V/R 계산값보다 작게 나올 수 있습니다. 실제 회로에서 전지 내부저항과 도선 저항 때문에 전류가 무한히 커지지 않는 것과 비슷합니다.
  • 직렬로 터널이 많아 화면에 다 들어가지 않으면 터널을 줄여서 그립니다. 저항 계산에는 설정한 길이가 그대로 쓰입니다.
